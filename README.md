# Konofix Android — isolated APK build workspace

This branch is a build-only workspace for a separate Konofix Android candidate.
It is not a change to Ghost APK Builder main and must not be merged into that branch.
Swir/Konofix is read-only. No desktop branches, releases, workflows or files are changed.

The candidate is not yet compiled or tested against a real PC. Only a signed APK produced
by a successful Android build may be offered for installation; a source ZIP is not an APK.

Pinned PC baseline: 31298cc732c97ff90230c3743cd1c3be17f40b6c (manifest 0.5.1).
